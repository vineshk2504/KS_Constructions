# BuildWell Construction Boilerplate

Next.js + TypeScript starter for a construction company website.

## Modules
- Home
- About Us
- Services
- Projects
- Ongoing Sites
- Gallery
- Construction Estimator
- Vastu
- Civil Supplies
- Appointment
- Contact

## Run
```bash
npm install
npm run dev
```

## Suggested ownership
Each route is intentionally isolated so a developer can own one module. Shared UI belongs in `components/`.

## Next additions
Tailwind CSS, form validation, database/CMS, project data model, estimator engine, appointment API, image storage, admin portal, SEO and analytics.
